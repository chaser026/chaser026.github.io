#### 残差连接的数学表达

残差连接的核心公式为：

$$y = x + f(x)$$

其中 $x$ 为输入，$f(x)$ 为子层（如 Attention 或 FFN）的非线性变换输出，$y$ 为子层的最终输出。

---

#### 网络退化与梯度消失

##### 网络退化（Degradation）

> [!WARNING]
> **注意：退化 ≠ 过拟合。** 过拟合表现为训练误差低而测试误差高；退化则是训练集准确率本身随深度增加而下降。

- **现象描述**：当模型深度增加时，训练集上的准确率会迅速达到饱和，随后开始退化。
- **本质原因一——信息磨损**：信号每经过一层非线性变换（线性变换再接 ReLU），都会丢失一部分原始信息。经过上百层累积，原始特征被"打碎"到模型无法识别。
- **本质原因二——恒等映射陷阱**：在数学优化上，让一个复杂的深层网络去学习"什么都不做"（即输出等于输入，$f(x)=0$）极其困难。由于权重初始化通常接近 0，模型更倾向于把输入抹平。

##### 梯度消失

在反向传播时，残差路径就是一条直达到底层的快捷通道。梯度不需要在复杂的权重森林里迷路，它顺着那条线直接回传到底层。

---

#### 残差连接的解决机制

残差连接通过引入一条"快捷通道（Shortcut）"，将网络结构从 $y = f(x)$ 重构为 $y = x + f(x)$。

- **赋予"不做功"的权利**：如果某一层是不必要的，优化器只需将 $f(x)$ 路径上的参数收缩至 0，模型就能实现完美的恒等映射。这顺应了 L2 正则化（Weight Decay）的本能，使得"保住原始信息"成为模型的默认选项。
- **信息逐层递增**：模型不再需要每一层都重新构建完整的特征描述，而是把输入 $x$ 作为保底底座，每一层只需学习相对于上一层的微小增量（残差）。这种"大底座 + 小补丁"的模式，确保有效信息在深层网络中不仅不会丢失，反而能不断精炼。

---

#### Pre-norm 与 Post-norm 对比

在 Transformer 的演进史上，归一化层（Norm）的位置经历过重大变革。

| 特性 | Post-norm（原始 Transformer） | Pre-norm（Llama 3 风格） |
|---|---|---|
| 公式 | $\text{Norm}(x + \text{Sublayer}(x))$ | $x + \text{Sublayer}(\text{Norm}(x))$ |
| Norm 位置 | 残差相加之后 | 子层运算之前 |
| 训练稳定性 | 深层网络输出方差随层数剧烈波动，训练初期极不稳定 | 梯度可直接通过残差路径流向底层，无需穿过归一化层 |
| 学习率策略 | 必须配合复杂的学习率预热（Warmup） | 对初始化更鲁棒，支持更深网络 |
| 适用规模 | 较浅模型 | 70B 甚至 405B 参数规模 |

> [!TIP]
> 本代码采用 **Pre-norm**（Llama 3 风格），即 Norm 放在子层运算之前。

---

#### Transformer Block 结构拆解

一个 Transformer Block 由两个子层（Sub-layers）组成：

1. **空间域通信（MHA）**：负责 token 之间的信息交互
2. **通道域提纯（FFN）**：负责逐位置的特征变换

##### 子层一：空间域通信（Multi-Head Attention）

```python
x = x + self.attn(self.ln1(x), token_positions=token_positions)
```

- **流程**：输入先经过 `ln1` 归一化，再进入 `attn`（因果自注意力）。
- **注意点**：必须将 `token_positions` 传递给 `self.attn`。这是因为使用了 RoPE，Attention 内部需要位置索引来计算旋转角度。

##### 子层二：通道域提纯（Feed-Forward Network）

```python
x = x + self.ffn(self.ln2(x))
```

- **流程**：上一步的输出再次经过 `ln2` 归一化，进入 `ffn`。
- **注意点**：FFN 是逐位（Position-wise）计算的，不依赖位置信息，因此不需要传位置参数。

---

#### 完整代码实现

```python
class TransformerBlock(nn.Module):
    def __init__(self, d_model: int, num_heads: int, d_ff: int, max_seq_len: int,
                 theta: float, device=None, dtype=None):
        super().__init__()
        # 初始化因果自注意力模块
        self.attn = CausalSelfAttention(
            d_model=d_model, 
            num_heads=num_heads, 
            max_seq_len=max_seq_len, 
            theta=theta,
            device=device, 
            dtype=dtype
        )
        # 初始化两个 RMSNorm 层，分别服务于 Attention 和 FFN
        self.ln1 = RMSNorm(d_model, device=device, dtype=dtype)
        self.ln2 = RMSNorm(d_model, device=device, dtype=dtype)
        
        # 初始化前馈网络 (SwiGLU)
        self.ffn = SwiGLU(d_model, d_ff, device=device, dtype=dtype)

    def forward(self, x: torch.Tensor, token_positions: torch.Tensor = None) -> torch.Tensor:
        # 步骤 1: Attention 子层 (Pre-norm 结构)
        # x 被分成两路：一路直接传走（残差），一路进 Norm+Attention
        x = x + self.attn(self.ln1(x), token_positions=token_positions)
        
        # 步骤 2: FFN 子层 (Pre-norm 结构)
        # 再次分流：一路直接传走，一路进 Norm+FFN
        x = x + self.ffn(self.ln2(x))
        
        return x
```

> [!NOTE]
> **参数说明**
> - `d_model`：模型隐藏维度
> - `num_heads`：注意力头数
> - `d_ff`：FFN 中间层维度
> - `max_seq_len`：最大序列长度
> - `theta`：RoPE 旋转角度的基频参数
> - `device` / `dtype`：设备与数据类型，默认为 `None`（使用模块默认设置）
