# 4.2 完整语言模型架构的组装

> [!NOTE]
> **本节目标**
> - 理解 TransformerLM 从 Token ID 到 Logits 的完整数据流与各模块职责
> - 掌握 `nn.ModuleList`、Final RMSNorm、LM Head 三个核心组件的设计动机与实现细节
> - 能够追踪张量在各阶段的维度变化，并独立实现完整的 `TransformerLM` 类

---

#### 架构总览：从 ID 到 Logits 的全链路

整个 `TransformerLM` 的计算逻辑可以类比为一条精密的流水线，数据依次经过四个阶段：

1. **入口（Embedding）**：将离散的整数 Token ID 映射为高维连续向量
2. **加工区（Layers）**：数据依次通过 $N$ 个结构相同的 `TransformerBlock`；每一层借助自注意力机制（信息通信）与前馈网络（特征计算）逐步提升抽象程度
3. **终检（Final Norm）**：在最终预测前对特征分布做最后一次标准化，保障数值稳定性
4. **出口（LM Head）**：将高维语义向量重新投影到词表维度，输出每个 Token 的预测分值（Logits）

> [!TIP]
> 上述四步对应 `forward` 方法中的四段核心逻辑，建议对照代码逐行阅读以加深理解。

---

#### 核心组件解析

##### nn.ModuleList：参数注册的容器

在实现中，我们使用 `nn.ModuleList` 来存储多个 `TransformerBlock` 实例。

- **为什么不用 Python 原生 `list`？** 原生列表中的模块不会被 PyTorch 的参数管理机制识别，导致 `model.to(device)` 或优化器无法正确遍历和更新这些层的参数。
- **`nn.ModuleList` 的作用**：自动将内部每个 Block 的参数注册到父模型中，确保设备迁移、梯度计算、参数保存等操作能覆盖所有层。

##### Final RMSNorm：Pre-norm 架构的收尾

根据 Pre-norm 架构规范，最后一个 Block 输出后必须再经过一次归一化。

- **物理意义**：由于残差连接的存在，随着层数加深，特征的数值范围可能逐渐偏移。`ln_final` 将分布重新拉回均值为 0、方差受控的状态，为后续线性投影提供"整齐"的输入。
- **边界条件**：当全局参数 `use_rms_norm=False` 时，`ln_final` 退化为 `nn.Identity()`（直通），不做任何变换。

> [!WARNING]
> 常见误区：忽略 Final Norm 直接将 Block 输出送入 LM Head，会导致训练初期 Loss 剧烈震荡甚至发散。

##### LM Head：从语义空间到词表空间

`lm_head` 是一个 `Linear(d_model, vocab_size)` 层。

- **作用**：将模型学到的 $d_{\text{model}}$ 维深层语义向量扩展到 $\text{vocab\_size}$ 维，决定模型最终"想说什么"。
- **输出含义**：得到的 Logits 尚未经过 Softmax，通常在训练时与 `CrossEntropyLoss` 配合使用（内部已包含 Softmax）。

---

#### 维度变化追踪

| 阶段 | 张量名称 | 形状 | 说明 |
|------|----------|------|------|
| 输入 | `token_ids` | $[\text{Batch},\ \text{Seq}]$ | 整数 Token ID |
| 嵌入后 | `x` | $[\text{Batch},\ \text{Seq},\ d_{\text{model}}]$ | Token Embedding 输出 |
| 经过 $N$ 个 Block 后 | `x` | $[\text{Batch},\ \text{Seq},\ d_{\text{model}}]$ | 形状保持不变 |
| 最终输出 | `logits` | $[\text{Batch},\ \text{Seq},\ \text{vocab\_size}]$ | LM Head 投影结果 |

---

#### 完整实现代码

以下是 `TransformerLM` 的完整实现，包含所有实验参数的透传逻辑：

```python
class TransformerLM(nn.Module):
    def __init__(self, vocab_size: int, max_seq_len: int, d_model: int, 
                 num_layers: int, num_heads: int, d_ff: int, rope_theta: float, 
                 device=None, dtype=None,
                 # 新增实验参数
                 use_rms_norm: bool = True,
                 norm_mode: str = "pre",
                 ffn_type: str = "swiglu"):
        super().__init__()
        self.max_seq_len = max_seq_len
        
        # 1. Token Embedding 层
        self.token_embeddings = Embedding(vocab_size, d_model, device=device, dtype=dtype)
        
        # 2. 堆叠 Transformer Blocks
        # 将实验参数透传给每一个 Block
        self.layers = nn.ModuleList([
            TransformerBlock(
                d_model, num_heads, d_ff, max_seq_len, rope_theta, 
                device=device, dtype=dtype,
                use_rms_norm=use_rms_norm,
                norm_mode=norm_mode,
                ffn_type=ffn_type
            )
            for _ in range(num_layers)
        ])
        
        # 3. 最终的输出层
        # 如果全局禁用了 Norm，这里的 Final Norm 也要变成 Identity
        if use_rms_norm:
            self.ln_final = RMSNorm(d_model, device=device, dtype=dtype)
        else:
            """
            forward(input):
                return input
            """
            self.ln_final = nn.Identity()

            
        # 最后是一个 Linear 层映射回词表大小 (LM Head)
        self.lm_head = Linear(d_model, vocab_size, device=device, dtype=dtype)

    def forward(self, token_ids: torch.Tensor) -> torch.Tensor:

        b, s = token_ids.shape
        
        # 准备位置信息用于 RoPE, shape: [S] -> [1, S] -> [B,S]
        token_positions = torch.arange(s, device=token_ids.device).unsqueeze(0).expand(b, s)
        
        # 1. Embedding
        x = self.token_embeddings(token_ids)
        
        # 2. 逐层通过 Transformer Blocks
        for layer in self.layers:
            x = layer(x, token_positions=token_positions)
            
        # 3. 最终归一化 (如果 use_rms_norm=False，这里就是直通)
        x = self.ln_final(x)
        
        # 4. 投影到词表空间得到 logits
        return self.lm_head(x)
```

> [!NOTE]
> **实现细节提醒**
> - `token_positions` 的构造利用了 `unsqueeze(0).expand(b, s)`，避免为每个样本单独生成位置编码，节省显存。
> - `use_rms_norm`、`norm_mode`、`ffn_type` 三个实验参数会被透传到每一个 `TransformerBlock`，确保全局配置一致。
> - 当 `use_rms_norm=False` 时，`ln_final` 替换为 `nn.Identity()`，此时 Final Norm 步骤完全跳过。
