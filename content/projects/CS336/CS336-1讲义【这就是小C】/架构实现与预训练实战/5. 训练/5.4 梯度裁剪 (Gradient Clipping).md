# 5.4 梯度裁剪 (Gradient Clipping)

在训练深层 Transformer 模型时，由于网络层数多且包含复杂的非线性变换，模型经常会遇到梯度爆炸的问题。本节将实现梯度裁剪，确保模型在不稳定的训练初期或遇到极端数据时不会崩溃。

> [!NOTE]
> **本节目标**
> - 理解梯度裁剪的作用与操作对象
> - 掌握梯度裁剪的使用位置与实现方式

---

## 梯度裁剪概述

梯度裁剪是一种在训练过程中防止梯度爆炸的稳定化技术。其核心思想是：在每次反向传播之后、优化器步进（Step）之前，检查所有参数梯度的总长度（Global Norm）；如果总长度超过了安全阈值 $M$，就按比例缩小梯度，确保步长在安全范围内，同时保持前进方向不变。

> [!TIP]
> **关键要点**：梯度裁剪不改变梯度的方向，只缩放其大小。这意味着模型仍然朝着损失下降的方向前进，只是步子被"收短"了。

---

## 数学原理：全局 L2 范数

梯度裁剪的核心是计算**全局 L2 范数**。将模型中所有层的梯度拼接成一个巨大的向量 $g$，然后计算它的欧几里得长度：

$$
\|g\|_2 = \sqrt{\sum_{i} L_i^2}
$$

其中 $L_i = \|g_i\|_2$ 是第 $i$ 层梯度的 L2 范数。

裁剪规则如下：

$$
\text{if } \|g\|_2 > M \text{, then } g \leftarrow g \times \frac{M}{\|g\|_2}
$$

即当全局范数超过阈值 $M$ 时，对所有梯度进行等比例缩放，缩放系数为 $\frac{M}{\|g\|_2}$。

---

## 实现细节

### 操作对象与使用位置

| 项目 | 说明 |
|------|------|
| 操作对象 | 模型所有参数的梯度（`model.parameters()`） |
| 使用位置 | 反向传播（`loss.backward()`）之后、优化器步进（`optimizer.step()`）之前 |
| 触发条件 | 全局 L2 范数超过预设阈值 `max_norm` |

### 完整实现代码

```python
import torch
from collections.abc import Iterable

def clip_gradient_norm(parameters: Iterable[torch.nn.Parameter], max_norm: float):
    """
    实现全局梯度裁剪 (Global Norm Clipping)。
    
    参数:
        parameters: 模型的所有参数 (model.parameters())
        max_norm: 允许的最大梯度 L2 范数 (M)
    """
    # 1. 过滤掉没有梯度的参数（防止对 None 对象操作）
    params_with_grad = [p for p in parameters if p.grad is not None]
    if not params_with_grad:
        return
    
    # 2. 计算全局 L2 范数 (Global L2 Norm)
    total_norm = 0.0
    for p in params_with_grad:
        # 使用 .detach() 极其重要：
        # 梯度裁剪是在计算完导数后进行的数值操作，我们不希望"计算范数"的过程也被记入计算图。
        # torch.norm(..., p=2) 算出当前层梯度的 L2 范数 L_i
        param_norm = torch.norm(p.grad.detach(), p=2)
        
        # 将各层范数的平方累加 (L_total = sqrt(sum(L_i^2)))
        total_norm += param_norm.item() ** 2
    
    total_norm = total_norm ** 0.5
    
    # 3. 检查是否触发裁剪
    eps = 1e-6  # 防止除零的稳定性常数
    if total_norm > max_norm:
        # 计算统一的缩放系数
        clip_coef = max_norm / (total_norm + eps)
        
        # 4. 原地 (in-place) 修改每个参数的梯度
        # 使用 mul_ 直接修改内存，不产生临时副本，节省显存
        for p in params_with_grad:
            p.grad.detach().mul_(clip_coef)
```

### 实现要点解析

- **过滤无梯度参数**：并非所有参数在每次迭代中都会产生梯度（如冻结层），必须先过滤掉 `grad is None` 的参数，避免对 `None` 对象调用方法。
- **使用 `.detach()`**：梯度裁剪属于数值后处理操作，不应被计入计算图。对 `p.grad` 调用 `.detach()` 可将其从计算图中分离。
- **稳定性常数 `eps`**：在计算缩放系数时加入 `1e-6`，防止 `total_norm` 接近零时出现除零错误。
- **原地操作 `.mul_()`**：直接在原梯度张量上修改，不产生临时副本，有助于节省显存。

> [!WARNING]
> **常见误区**：不要在 `loss.backward()` 之前调用梯度裁剪函数，此时梯度尚未计算；也不要在 `optimizer.step()` 之后调用，此时梯度已被优化器消费。正确顺序为：`backward()` → `clip_gradient_norm()` → `step()`。
