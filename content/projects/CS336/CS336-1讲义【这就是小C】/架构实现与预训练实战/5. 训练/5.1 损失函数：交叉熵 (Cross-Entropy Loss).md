# 5.1 损失函数：交叉熵 (Cross-Entropy Loss)

> [!NOTE]
> **本节目标**
> - 理解损失函数的操作对象（Logits 与 Target 的对齐关系）
> - 掌握数值稳定性技巧（Log-Sum-Exp）及其工程实现

---

#### 核心概念：交叉熵衡量什么？

在语言模型任务中，交叉熵损失函数衡量的是模型对"下一个词"预测的准确度。其核心逻辑是：

- 让正确 ID 对应的 Logits 分值尽可能**高**
- 让其他无关词的分值尽可能**低**

---

#### 输入对齐：Logits 与 Target

| 张量 | 形状 | 含义 |
|------|------|------|
| 模型输出 (Logits) | `[Batch, SeqLen, VocabSize]` | 模型认为词表中每个词作为下一个词的"能量分值"，**未经 Softmax**，数值范围可能很大 |
| 真实标签 (Target) | `[Batch, SeqLen]` | 标准答案在词表中的索引 ID |

> [!TIP]
> Logits 是 Softmax 之前的原始分值，不是概率。直接对 Logits 做交叉熵计算可以避免先算概率再取对数带来的精度损失。

---

#### 从概率定义到工程公式

**1. 原始定义（Softmax + Negative Log Likelihood）**

对于某个位置的输出向量 $\mathbf{o}$ 和正确索引 $y$，损失 $\ell$ 的标准定义为：

$$\ell = -\log\left(\frac{\exp(o_y)}{\sum_{j=1}^{V}\exp(o_j)}\right)$$

其中 $V$ 为词表大小，$o_y$ 是正确类别对应的 Logit。

**2. 工程化拆解（对数运算律）**

利用 $\log\frac{a}{b} = \log a - \log b$，将公式展开：

$$\ell = -o_y + \log\left(\sum_{j=1}^{V}\exp(o_j)\right)$$

> [!NOTE]
> 这个公式在工程上更受欢迎，因为它**减少了除法操作**，并将复杂的比值转化为了**减法**，计算更高效且数值更稳定。

---

#### 数值稳定性：Log-Sum-Exp 技巧

在训练几百亿参数的大模型时，Logits 的数值往往会失控。直接计算 $\sum\exp(o_j)$ 会面临两大杀手：

| 问题 | 触发条件 | 后果 |
|------|----------|------|
| 上溢 (Overflow) | Logits 中出现较大正值（如 89），$\exp(89)$ 超过 FP32 上限 $\approx 3.4\times10^{38}$ | 结果变为 `Inf`，Loss 变为 `NaN` |
| 下溢 (Underflow) | Logits 全是很小的负数（如 -100），$\exp(-100)$ 变为 0 | 分母所有项下溢成 0，除法崩溃 |

**对策：减去最大值**

利用恒等式：

$$\log\sum_{j=1}^{V}\exp(o_j) = M + \log\sum_{j=1}^{V}\exp(o_j - M)$$

其中 $M = \max_j(o_j)$。

**稳定公式推导**：

$$\ell = -o_y + \left[M + \log\sum_{j=1}^{V}\exp(o_j - M)\right]$$

**为什么这样就稳了？**

- 减去 $M$ 后，$o_j - M$ 的最大值正好是 $0$，因此 $\exp(0) = 1$
- $\sum\exp(o_j - M) \geq 1$，彻底杜绝了分母为 $0$ 的下溢风险
- 所有指数项都在 $(0, 1]$ 之间，彻底杜绝了数值爆炸的上溢风险

> [!WARNING]
> 单精度浮点数（FP32）能表示的最大值约为 $3.4\times10^{38}$。即使 Logits 只出现 89 这样的值，$\exp(89) \approx 1.2\times10^{38}$ 已接近上限，稍大一点就会溢出。

---

#### 完整计算示例

假设极小场景：

| 参数 | 值 |
|------|-----|
| Batch Size (B) | 1（一个句子） |
| Sequence Length (S) | 2（两个单词） |
| Vocab Size (V) | 3（词表：A, B, C） |

**1. 输入数据**

模型输出 Logits（shape: `(1, 2, 3)`）：

- 位置 1：`[2.0, 1.0, 0.1]`（模型最看好 A）
- 位置 2：`[0.5, 3.0, 1.2]`（模型最看好 B）

真实标签 Targets（shape: `(1, 2)`）：

- `[0, 1]`（正确答案：位置 1 是 A，位置 2 是 B）

**2. 步骤拆解**

**第一步：计算最大值 $M$（数值稳定）**

- 位置 1 最大值：$M_1 = 2.0$
- 位置 2 最大值：$M_2 = 3.0$
- $M$ 形状为 `(1, 2, 1)`

**第二步：提取目标位置分值 $o_y$（使用 gather）**

- 位置 1 提取索引 0 的值：$o_{y_1} = 2.0$
- 位置 2 提取索引 1 的值：$o_{y_2} = 3.0$
- `target_logits = [2.0, 3.0]`

**第三步：计算 Log-Sum-Exp**

以位置 1 为例：

1. 减去最大值：$[2.0-2.0,\ 1.0-2.0,\ 0.1-2.0] = [0,\ -1.0,\ -1.9]$
2. 取指数并求和：$\exp(0) + \exp(-1.0) + \exp(-1.9) = 1 + 0.3679 + 0.1496 = 1.5175$
3. 取对数并加回 $M$：$\log(1.5175) + 2.0 = 0.417 + 2.0 = 2.417$

同理可得位置 2：

1. 减去最大值：$[0.5-3.0,\ 3.0-3.0,\ 1.2-3.0] = [-2.5,\ 0,\ -1.8]$
2. 取指数并求和：$\exp(-2.5) + \exp(0) + \exp(-1.8) = 0.0821 + 1 + 0.1653 = 1.2474$
3. 取对数并加回 $M$：$\log(1.2474) + 3.0 = 0.221 + 3.0 = 3.221$

**第四步：计算 Token Loss $\ell = \text{LSE} - o_y$**

- 位置 1 损失：$\ell_1 = 2.417 - 2.0 = 0.417$
- 位置 2 损失：$\ell_2 = 3.221 - 3.0 = 0.221$

**第五步：求全批次平均 (Mean)**

$$\text{Loss} = \frac{0.417 + 0.221}{2} = 0.319$$

---

#### 工程实现

```python
import torch

def cross_entropy(logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
    """
    计算数值稳定的交叉熵损失。
    
    参数:
        logits: 形状为 (Batch, Seq, Vocab_size) 的预测分值
        targets: 形状为 (Batch, Seq) 的真实 Token ID
    """
    
    # 1. 计算每组 Logits 的最大值 M，用于数值稳定
    # dim=-1 表示在词表维度搜索，keepdim=True 保证结果形状为 (Batch, Seq, 1)
    # 这样在后续执行 'logits - m' 时可以触发自动广播
    m = torch.max(logits, dim=-1, keepdim=True).values
    
    # 2. 提取目标位置对应的原始分值 o_y
    # 使用 gather 函数从词表维度中根据 targets 提取对应的分值
    # 由于 gather 要求 index 的维度与输入一致，需将 targets 升维成 (Batch, Seq, 1)
    target_logits = torch.gather(logits, dim=-1, index=targets.unsqueeze(-1)).squeeze(-1)
    
    # 3. 计算 Log-Sum-Exp 项
    # shifted_logits 最大值为 0，exp 运算安全
    shifted_logits = logits - m
    
    # 公式：M + log(sum(exp(o - M)))
    # 注意：m 提取出来后形状是 (B, S, 1)，求和项形状是 (B, S)，相加时需先 squeeze m
    log_sum_exp = m.squeeze(-1) + torch.log(torch.sum(torch.exp(shifted_logits), dim=-1))
    
    # 4. 计算每个 Token 的独立损失值
    # shape:[B,S]
    loss = log_sum_exp - target_logits
    
    # 5. 按照作业要求，对整个批次求平均，返回一个标量
    # loss.backward()
    return torch.mean(loss)
```

> [!TIP]
> 实现要点回顾：
> - `torch.max(..., keepdim=True)` 保持维度以支持广播
> - `torch.gather` 提取目标位置分值时需对 `targets` 做 `unsqueeze(-1)` 升维
> - 最终 `torch.mean(loss)` 对整个批次求平均，返回标量
