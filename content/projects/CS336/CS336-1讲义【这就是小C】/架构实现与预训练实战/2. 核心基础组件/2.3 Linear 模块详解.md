## 2.3.1 数学定义 vs. 工程现实

### 数学视角

在数学教科书中，输入通常被视为**列向量**：

- 输入 $x$ 的维度：$\mathbb{R}^{d_{\text{in}} \times 1}$
- 权重 $W$ 的维度：$\mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$
- 输出 $y = Wx$ 的维度：$\mathbb{R}^{d_{\text{out}} \times 1}$

### PyTorch 工程视角

计算机内存采用**行主序（Row-major）** 存储。为高效处理 Batch 数据，PyTorch 将输入组织为**行向量**：

| 张量 | 形状 | 说明 |
|------|------|------|
| 输入 $x$ | $[\text{Batch},\; \text{in\_features}]$ | 每行是一个样本 |
| 权重 $W$ | $[\text{out\_features},\; \text{in\_features}]$ | 每行对应一个输出神经元 |
| 输出 $y$ | $[\text{Batch},\; \text{out\_features}]$ | 每行是一个样本的输出 |

计算逻辑：为使维度匹配，需对 $W$ 转置，执行 $x \; @ \; W^\top$。

> [!TIP]
> **为什么权重存为 `(out, in)` 而非 `(in, out)`？**
>
> 在 `(out, in)` 布局下，权重矩阵的每一行对应输出空间的一个"神经元"。执行矩阵乘法时，计算机可以**连续读取一整行内存到缓存（Cache）**，极大提升运算速度——这就是内存局部性（Locality）的优势。

## 2.3.2 权重初始化：Xavier 的思想

Linear 层对初始值极其敏感：

- 初始值**太大** → 输出瞬间爆炸
- 初始值**太小** → 信号迅速衰减

### 截断正态分布初始化（Truncated Normal Initialization）

我们采用截断正态分布来初始化权重，其关键参数如下：

| 参数 | 公式 / 值 | 说明 |
|------|-----------|------|
| 标准差 $\sigma$ | $\sigma = \sqrt{\dfrac{2}{d_{\text{in}} + d_{\text{out}}}}$ | 保持层间输出方差一致，确保信号能传到深层 |
| 截断范围 | $[-3\sigma,\; +3\sigma]$ | 剔除正态分布"长尾"处的极端异常值 |

> [!WARNING]
> **为什么要截断？**
>
> 正态分布的长尾会产生极端异常值。若不截断，模型在第一步训练时就可能因某个随机数过大而产生 NaN，导致训练崩溃。

### 代码实现

```python
import torch
import torch.nn as nn

class Linear(nn.Module):
    def __init__(self, in_features: int, out_features: int, device=None, dtype=None):
        super().__init__()
        self.in_features = in_features
        self.out_features = out_features
        
        # 1. 准备工厂参数
        factory_kwargs = {'device': device, 'dtype': dtype}
        
        # 2. 占坑：定义权重参数 W (形状: out x in)
        # 注意：这里不用 bias，符合现代 LLM (如 Llama) 的做法
        self.weight = nn.Parameter(torch.empty((out_features, in_features), **factory_kwargs))
        
        # 3. 填土：执行截断正态分布初始化
        std = (2.0 / (in_features + out_features)) ** 0.5
        nn.init.trunc_normal_(self.weight, mean=0.0, std=std, a=-3*std, b=3*std)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x 形状: [..., in_features]
        # 使用 einsum 表达: "输入的最后一位 i 与 权重的最后一位 i 相乘，输出 o"
        # 这种写法比 x @ self.weight.T 更具可读性，且支持任意 Batch 维度
        return torch.einsum('...i, oi -> ...o', x, self.weight)
```

> [!NOTE]
> **`torch.einsum` 解读**
>
> - `...i`：输入张量的最后一维为 $i$（即 `in_features`），`...` 表示任意数量的前置维度（如 Batch）
> - `oi`：权重张量的维度为 $o \times i$（即 `out_features × in_features`）
> - `...o`：输出张量保留输入的前置维度，最后一维变为 $o$（即 `out_features`）
>
> 该写法比 `x @ self.weight.T` 更具可读性，且天然支持任意 Batch 维度。
