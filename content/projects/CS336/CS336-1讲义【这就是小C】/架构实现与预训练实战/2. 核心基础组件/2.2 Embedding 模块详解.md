## Embedding 的核心概念

### 本质：从离散 ID 到连续向量

Embedding 层的任务是：**为词表中的每一个 Token ID 分配一个长度为 $d_{\text{model}}$ 的浮点数向量**。

其工作机制可以概括为一次查表操作：

- **输入**：Token ID（一个整数）
- **输出**：权重矩阵中的第 $i$ 行（一个 $d_{\text{model}}$ 维向量）

#### 维度流转

| 阶段 | 张量形状 | 含义 |
|------|----------|------|
| 输入 | $[B, S]$ | Batch Size × Seq Len |
| 输出 | $[B, S, D]$ | Batch Size × Seq Len × $d_{\text{model}}$ |

> [!TIP]
> 在原始 ID 空间中，10 和 11 只是两个孤立的离散点；但映射到向量空间后，模型可以通过训练让语义相近的词（如"猫"和"狗"）在几何距离上更接近。这正是 Embedding 赋予模型处理语义相似性能力的关键所在。

## PyTorch 核心基础组件

在手写 Embedding 层之前，需要先理解 PyTorch 提供的三个"基础设施"组件。

### nn.Module：模型基类

- 所有神经网络模块的"母体"，继承后 PyTorch 会自动追踪所有子模块和参数
- 提供 `.to(device)`（一键搬运到 GPU）、`.train()` / `.eval()`（切换训练/推理模式）等核心功能

### nn.Parameter：被标记的张量

`nn.Parameter` 本质上是一种特殊的 `Tensor`，但具有关键区别：

| 使用场景 | 推荐方式 | 说明 |
|----------|----------|------|
| 需要通过优化器更新、随模型保存 | `nn.Parameter` | 自动加入 `parameters()` 迭代器 |
| 需要随模型移动设备、保存，但不更新梯度 | `register_buffer` | 不参与梯度计算 |
| 临时中间变量 | 普通 `Tensor` | 不被模型追踪 |

> [!IMPORTANT]
> 只有被标记为 `nn.Parameter` 的张量，优化器（Optimizer）才能"看"到它并更新其梯度。这是模型可训练参数的根本标识。

### torch.empty：内存分配

- 与 `torch.zeros` / `torch.ones` 不同，`torch.empty` **只申请内存空间，不进行数据填充**，此时矩阵中的值是内存中的随机残留（Garbage Values）
- **工程意义**：在紧接着进行手动初始化的场景下，`empty` 比 `zeros` 更高效（省去了一次无意义的写零操作）

## Embedding 层实现

### 设计要点

1. **定义权重矩阵**：使用 `torch.nn.Parameter` 包装权重，使 PyTorch 自动计算梯度并允许优化器更新；形状为 $(\text{vocab\_size}, d_{\text{model}})$
2. **参数初始化（Truncated Normal）**：
   - 均值 $\mu = 0$
   - 标准差 $\sigma = 1.0$
   - 截断范围：$[-3, 3]$（即正负 3 倍标准差）
   - **目的**：防止初始值过大导致模型训练初期失去稳定性
3. **前向传播逻辑**：直接利用 PyTorch 的索引语法 `self.weight[token_ids]` 完成查表

### 完整代码

```python
import torch
import torch.nn as nn

class Embedding(nn.Module):
    def __init__(self, num_embeddings: int, embedding_dim: int, device=None, dtype=None):
        super().__init__()
        # 1. 分配内存并包装为参数 (W 维度: vocab_size x d_model)
        factory_kwargs = {'device': device, 'dtype': dtype}
        self.weight = nn.Parameter(torch.empty((num_embeddings, embedding_dim), **factory_kwargs))
        
        # 2. 按照作业要求执行初始化
        # mean=0, std=1.0, 截断在 [-3, 3]
        nn.init.trunc_normal_(self.weight, mean=0.0, std=1.0, a=-3.0, b=3.0)

    def forward(self, token_ids: torch.Tensor) -> torch.Tensor:
        # token_ids 形状: [B, S]
        # 直接通过索引从矩阵中"捞出"对应的向量
        return self.weight[token_ids]  # 返回形状: [B, S, D]
```

> [!NOTE]
> `forward` 方法中的索引操作 `self.weight[token_ids]` 是 PyTorch 的高级索引（Advanced Indexing），它会根据 `token_ids` 中的每个整数取出权重矩阵对应行，自动完成从 $[B, S]$ 到 $[B, S, D]$ 的维度扩展。
