# 2.1 Transformer 模块串讲

> [!NOTE]
> **本节目标**
> - 给定输入数据 $[B, S]$，理解其经过各模块后的形状变化与含义变化
> - 掌握从整数 ID 到最终词概率的完整数据流与关键计算

---

#### 数据流总览

整个 Transformer 的前向传播可以概括为以下流水线：

| 阶段 | 模块 | 形状变化 | 核心作用 |
|------|------|----------|----------|
| 输入 | Tokenizer | 文本 → $[B, S]$ | 文本切分为整数 ID 序列 |
| 映射 | Embedding | $[B, S]$ → $[B, S, d_{\text{model}}]$ | ID 映射为连续特征向量 |
| 变换 | Transformer Block × N | $[B, S, d_{\text{model}}]$（不变） | 信息交换与特征提炼 |
| 输出 | RMSNorm + LM Head | $[B, S, d_{\text{model}}]$ → $[B, S, \text{vocab\_size}]$ | 生成下一个词的概率分布 |

---

#### 输入阶段：从文本到整数张量

原始输入是一批文本，经 Tokenizer 转换后得到一个二维整数张量：

- **形状**：$[B, S]$，其中 $B$ 为 Batch Size，$S$ 为 Seq Len
- **示例**：

```text
[[332, 545, 612],
 [866, 959, 1402]]
```

> 2 条句子，每条 3 个 Token。

> [!WARNING]
> 整数 ID 之间不存在数学上的相关性——ID 10 和 ID 11 并不代表语义接近。因此需要将其映射到高维连续空间。

---

#### 映射阶段：Embedding 模块

Embedding 本质上是一个巨大的查找表，形状为 $[\text{vocab\_size}, d_{\text{model}}]$。

- **作用**：将每个整数 ID 转换为长度为 $d_{\text{model}}$ 的浮点数向量
- **形状变化**：$[B, S] \rightarrow [B, S, d_{\text{model}}]$
- **意义**：每个 Token 拥有了自己的特征向量；语义相近的 Token 在该空间中距离更近

---

#### 核心变换：Transformer Block

数据进入堆叠的 Block（共 $N$ 层），这是模型"思考"与"特征提炼"的核心单元。每个 Block 包含两个子层：

1. **因果多头自注意力层**——负责 Token 间的信息交换
2. **前馈网络层（FFN / SwiGLU）**——负责 Token 自身特征的深度加工

---

##### 因果多头自注意力（Causal Multi-Head Self-Attention）

###### Q、K、V 的本质

每个 Token 向量通过线性投影生成三个身份：

| 角色 | 含义 | 类比 |
|------|------|------|
| Query (Q) | 我想找什么？ | 当前位置的搜索词 |
| Key (K) | 我能提供什么？ | 所有位置的索引标签 |
| Value (V) | 我具体的内容是什么？ | 所有位置的信息内容 |

计算逻辑：通过 $Q$ 与 $K$ 的点积相似度，决定当前 Token 应分配多少注意力给上下文中的其他 Token，最后对 $V$ 进行加权求和：

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V$$

###### 多头机制（Multi-Head）

- **逻辑**：不直接在 $d_{\text{model}}$ 全维度上计算一次注意力，而是拆分为 $h$ 个低维的"头"
- **目的**：允许模型在不同子空间中并行学习不同类型的关系（例如：头 1 关注指代关系，头 2 关注时态信息，头 3 关注句式结构）

###### 维度演变

| 步骤 | 操作 | 形状 |
|------|------|------|
| 输入 | 原始嵌入 | $[B, S, d_{\text{model}}]$ |
| 投影 | 分别乘以 $W_Q, W_K, W_V$ | 三个 $[B, S, d_{\text{model}}]$ 张量 |
| 拆分 | Reshape 并转置 | $[B, h, S, d_k]$，其中 $d_k = d_{\text{model}} / h$ |
| 合并 | 拼接所有头后通过 $W_O$ 还原 | $[B, S, d_{\text{model}}]$ |

###### 因果掩码（Causal Mask）

- **实现**：在计算 $QK^{\top}$（形状 $[S, S]$）时，将右上角（未来信息）填充为 $-\infty$
- **作用**：确保第 $t$ 个位置做 Softmax 时，未来位置的权重降为 0，严格遵守单向因果律（只能看过去）

> [!NOTE]
> 因果掩码是自回归语言模型的关键约束，保证训练和推理时不会"偷看"未来 Token。

###### 位置编码（RoPE）

- **逻辑**：在投影得到 $Q$、$K$ 后，对其应用复数域或旋转矩阵变换
- **意义**：给 $Q$ 和 $K$ 注入旋转相位，使它们的点积结果直接受到"相对距离"的影响

---

##### 前馈网络（FFN / SwiGLU）

注意力层完成"空间维度"（Token 与 Token 之间）的信息交换后，FFN 在"通道维度"（Token 自身的特征）进行深度加工。

###### SwiGLU 结构（Llama 3 标配）

传统 FFN 是两层线性层中间加一个 ReLU；SwiGLU 引入了门控机制：

$$\text{SwiGLU}(x) = (xW_{\text{gate}} \cdot \text{SiLU}(xW_{\text{up}})) \, W_{\text{down}}$$

###### 维度操作与升维

- **升维**：通常将维度从 $d_{\text{model}}$ 提升至 $d_{\text{ff}}$（常见为 $4 \times d_{\text{model}}$）
- **形状变化**：$[B, S, d_{\text{model}}] \rightarrow [B, S, d_{\text{ff}}] \rightarrow [B, S, d_{\text{model}}]$

> [!IMPORTANT]
> 如果说注意力机制是"把相关的词聚在一起"，那么 FFN 就是"对聚合后的信息进行逻辑推理和存储"。大模型中绝大部分的知识和逻辑推理能力都被认为存储在 FFN 的参数中。

---

#### 输出层：从隐藏特征到词概率

经过 $N$ 层 Block 后，输出张量形状依然是 $[B, S, d_{\text{model}}]$。

##### 最终归一化（RMSNorm）

在输出前进行最后一次标准化，稳定梯度。

##### LM Head（线性输出层）

- **动作**：使用一个巨大的 Linear 层，将向量维度从 $d_{\text{model}}$ 映射回 $\text{vocab\_size}$
- **形状变化**：$[B, S, d_{\text{model}}] \rightarrow [B, S, \text{vocab\_size}]$

##### Softmax 概率化与训练目标

对 $\text{vocab\_size}$ 维度进行 Softmax 运算，得到每一个词出现的概率。

训练时，位置 $t$ 对应的真实标签是 $t+1$。模型给真实标签分配的概率越大，交叉熵损失（Loss）就越小。\n
