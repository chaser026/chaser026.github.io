---

#### 多头机制的核心动机

单头自注意力只能在一个特征子空间中计算注意力，表达能力有限。多头机制通过将模型维度拆分为多个子空间，让不同的头并行关注序列中不同类型的特征，从而提升模型的表征能力。

**并行专家制的直觉**：

- 将 $d_{\text{model}}$ 维拆分为 $h$ 个子空间，每个头的维度为 $d_k = d_{\text{model}} / h$
- 不同头可以"专攻"不同的语言现象：
  - 头 1：语法结构（如定位谓语动词）
  - 头 2：代词指代消解（如将"它"指向"苹果"）
  - 头 3：短距离修饰关系
- 最终通过输出投影层（Output Projection）将各头信息重新整合

> [!TIP]
> 多头并非简单地重复计算，而是让模型在不同表示子空间中同时捕获多样化的依赖关系。

---

#### 维度变化全流程

在代码实现中，最核心的任务是确保张量形状在"拆分"和"合并"过程中完全对齐。

以典型参数为例：$B=1$（batch）、$S=4$（序列长度）、$D=64$（模型维度）、$H=4$（头数），则每个头维度 $d_k = 64 / 4 = 16$。

| 步骤 | 操作内容 | 张量形状 (Shape) |
|------|----------|-----------------|
| 输入 | 原始隐藏层状态 | $[1, 4, 64]$ |
| 投影 | Q / K / V 三次线性投影 | $[1, 4, 64]$ |
| 拆分头 | 将 $d$ 拆为 $h \times d_k$，并将 $h$ 维移到序列维之前 | $[1, 4, 4, 16]$ |
| RoPE | 对 Q、K 应用旋转位置编码 | $[1, 4, 4, 16]$（形状不变） |
| SDPA | 计算缩放点积注意力 | $[1, 4, 4, 16]$（形状不变） |
| 合并头 | 将 $h$ 维度重新压回特征维度 | $[1, 4, 64]$ |
| 输出 | 最终线性变换 | $[1, 4, 64]$ |

---

#### 关键技术细节

##### 1. 三次矩阵乘法的设计

使用三个大的线性层 `Linear(d_model, d_model)` 一次性算出 Q、K、V 的全量投影，而非为每个头单独做乘法。这样做的原因：

- 充分利用 GPU 对大矩阵运算的并行优化
- 代码更简洁，避免循环开销

##### 2. 因果掩码的物理实现

使用 `torch.tril` 生成下三角布尔矩阵，确保位置 $i$ 的 Query 只能"看到"位置 $\leq i$ 的 Key。

示例（$S=4$）：

$$
\begin{bmatrix}
T & F & F & F \\
T & T & F & F \\
T & T & T & F \\
T & T & T & T
\end{bmatrix}
$$

> [!NOTE]
> 当 Query 在位置 1（第二行）时，它只能关注 Key 维度的第 0 和第 1 列——这就是"因果"的含义：未来信息不可见。

---

#### 完整代码实现

```python
import torch
import torch.nn as nn
from einops import rearrange  # 强烈推荐：使维度交换语义清晰

class CausalSelfAttention(nn.Module):
    def __init__(self, d_model: int, num_heads: int, max_seq_len=None, theta=None, device=None, dtype=None):
        super().__init__()
        # 维度校验
        assert d_model % num_heads == 0, "d_model 必须能被 num_heads 整除"
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # 1. Q, K, V 投影层：将输入映射到三个不同的特征空间
        self.q_proj = Linear(d_model, d_model, device=device, dtype=dtype)
        self.k_proj = Linear(d_model, d_model, device=device, dtype=dtype)
        self.v_proj = Linear(d_model, d_model, device=device, dtype=dtype)
        
        # 2. 输出投影层：整合所有头的信息
        self.output_proj = Linear(d_model, d_model, device=device, dtype=dtype)
        
        # 3. RoPE 初始化：仅在提供 theta 时启用
        if theta is not None and max_seq_len is not None:
            self.rope = RotaryPositionalEmbedding(theta, self.d_k, max_seq_len, device=device)
        else:
            self.rope = None

    def forward(self, x: torch.Tensor, token_positions: torch.Tensor = None) -> torch.Tensor:
        b, s, d = x.shape
        
        # 步骤 1 & 2: 线性投影并拆分多头
        # 使用 einops.rearrange 替代 view + transpose
        # 语义：将长度为 d 的特征维拆成 (h d_k)，并将 h 维移动到序列维 s 之前
        q = rearrange(self.q_proj(x), '... s (h d) -> ... h s d', h=self.num_heads)
        k = rearrange(self.k_proj(x), '... s (h d) -> ... h s d', h=self.num_heads)
        v = rearrange(self.v_proj(x), '... s (h d) -> ... h s d', h=self.num_heads)
        
        # 步骤 3: 应用 RoPE 旋转位置编码
        if self.rope is not None:
            if token_positions is None:
                # 默认生成从 0 开始的顺序位置
                # expand 处理 Batch 维度，不占用额外物理内存
                token_positions = torch.arange(s, device=x.device).expand(b, s)
            
            # 对 Q 和 K 进行旋转，V 保持不动
            q = self.rope(q, token_positions)
            k = self.rope(k, token_positions)

        # 步骤 4: 生成因果掩码 (下三角矩阵)
        # 确保 Query 只能看到当前及以前的 Key
        mask = torch.tril(torch.ones(s, s, device=x.device, dtype=torch.bool))

        # 步骤 5: 核心注意力计算 (SDPA)
        # 结果形状: (Batch, Heads, Seq, d_k)
        attn_out = scaled_dot_product_attention(q, k, v, mask=mask)
        
        # 步骤 6: 合并多头
        # 语义：将多头维度 h 重新并入特征维度
        attn_out = rearrange(attn_out, '... h s d -> ... s (h d)')
        
        # 步骤 7: 输出投影
        return self.output_proj(attn_out)
```

> [!WARNING]
> `d_model` 必须能被 `num_heads` 整除，否则拆分头时维度无法对齐，会在运行时报错。这是实现多头注意力的基本前提条件。\n
