## 归一化的核心概念

### 作用对象与计算频率

归一化层（Norm）的目标是将神经网络每一层输出的数值强行"拉回"到标准范围，防止信号在深层网络中失控。

- **作用对象**：将每一个 Token 看作独立个体。在形状为 $(B, T, d)$ 的张量中，归一化针对的是最后一个维度 $d$（特征维度）。
- **计算频率**：在一个 Batch 中，独立执行 $B \times T$ 次归一化计算。

### 为什么大模型离不开归一化

#### 维度一：训练稳定性

大语言模型（LLM）通常包含上百层 Transformer Block。如果没有归一化，信号传播就像"传声筒"游戏，误差会逐层放大。

> [!WARNING]
> **蝴蝶效应示例**：假设初始信号幅度为 1，每层放大 1.1 倍（增加 0.1），经过 100 层后信号幅度为 $1.1^{100} \approx 13780$。信号会迅速爆炸（NaN）或消失（趋近 0），导致梯度崩溃。

LayerNorm 的方案是在每一层出口安装"自动调音器"，强行将输出拉回均值 0、方差 1，确保无论模型多深，能量始终恒定。

#### 维度二：训练速度

若特征维度尺度不一（例如维度 A 范围 0~1000，维度 B 范围 0~1），Loss 空间会形成极度扁平的"深谷"。梯度下降时极易震荡，迫使使用极小的学习率。

> [!TIP]
> **直觉理解**：LayerNorm 通过对齐所有维度的尺度，将 Loss 地形重塑为圆形的"大盆地"。盆地中坡度均匀，可以放心使用更大的学习率，训练效率显著提升。

## LayerNorm：中心化 + 缩放

### 数学公式

LayerNorm 对向量 $x \in \mathbb{R}^d$ 的处理分为两个标准步骤：

1. **中心化（Centering）**：算出均值 $\mu = \frac{1}{d}\sum_{i=1}^{d} x_i$，让向量所有元素减去它，使中轴线对齐到 0。
2. **缩放（Scaling）**：算出标准差 $\sigma = \sqrt{\frac{1}{d}\sum_{i=1}^{d}(x_i - \mu)^2}$，让向量除以它，使分布宽度（方差）变成 1。

最终公式：

$$y = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta$$

其中：
- $\epsilon$：一个极小的常数（如 $10^{-5}$），防止除以 0。
- $\gamma$（weight）与 $\beta$（bias）：可学习参数，允许模型在必要时打破"均值 0 / 方差 1"的束缚，自主调节信号的幅度和偏移。

### 代码实现

> [!NOTE]
> 请特别注意 `mean` 函数中 `dim` 参数的选择，以及 `keepdim=True` 在广播机制中的作用。

```python
class LayerNorm(nn.Module):
    def __init__(self, d_model: int, eps: float = 1e-5, device=None, dtype=None):
        """
        LayerNorm 的手动实现。
        与 RMSNorm 相比，它同时处理了均值（Mean）和方差（Variance）。
        """
        super().__init__()
        factory_kwargs = {'device': device, 'dtype': dtype}
        
        # 1. 学习参数初始化
        # weight (gamma): 缩放参数，初始化为全 1
        self.weight = nn.Parameter(torch.ones(d_model, **factory_kwargs))
        # bias (beta): 偏移参数，初始化为全 0
        # 这是 LayerNorm 独有的，RMSNorm 通常不使用 bias
        self.bias = nn.Parameter(torch.zeros(d_model, **factory_kwargs))
        
        self.eps = eps

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x 形状: (batch_size, sequence_length, d_model)
        
        in_dtype = x.dtype
        # 2. 转换为 float32 以确保计算均值和方差时的数值稳定性（防止溢出）
        x_float = x.to(torch.float32)

        # 3. 计算均值 (Mean)
        # 对最后一个维度（特征维）求平均，keepdim=True 用于后续减法广播
        # 公式: E[x]
        mean = x_float.mean(dim=-1, keepdim=True)

        # 4. 计算方差 (Variance)
        # 公式: Var(x) = E[(x - E[x])^2]
        # 注意：这里使用 biased variance，与 PyTorch 官方 nn.LayerNorm 对齐
        var = x_float.var(dim=-1, keepdim=True, unbiased=False)

        # 5. 归一化 (Standardization)
        # 减去均值进行"中心化"，除以标准差进行"缩放"
        # 公式: (x - mean) / sqrt(var + eps)
        x_normed = (x_float - mean) / torch.sqrt(var + self.eps)

        # 6. 应用可学习的增益(weight)和偏置(bias)
        # 公式: y = x_normed * gamma + beta
        result = x_normed * self.weight + self.bias

        # 7. 转回输入时的原始数据类型 (如 bfloat16 或 float16)
        return result.to(in_dtype)
```

## RMSNorm：去掉均值，只留均方根

### 公式定义

对于一个 $d$ 维的激活向量 $a$，RMSNorm 的归一化过程如下：

$$a_{\text{norm}} = \frac{a}{\text{RMS}(a)} \cdot g$$

其中均方根（RMS）的计算公式为：

$$\text{RMS}(a) = \sqrt{\frac{1}{d}\sum_{i=1}^{d} a_i^2 + \epsilon}$$

- $\epsilon$：一个微小的常数（如 $10^{-5}$），防止除以 0。
- $g$（weight）：一个可学习的增益参数（Gain），维度与隐藏层 $d$ 一致。

> [!IMPORTANT]
> **核心观察**：研究表明，LayerNorm 中"减去均值"的操作对模型性能的贡献微乎其微，反而增加了额外的计算开销。RMSNorm 正是基于这一发现而设计。

### 具象化数值案例

假设 $d=2$（特征维为 2），输入向量为 $[3, 4]$，增益参数 $g$ 初始为 $[1, 1]$：

1. **平方均值（Mean Square）**：$(3^2 + 4^2) / 2 = 25 / 2 = 12.5$
2. **开方（Root）**：$\sqrt{12.5} \approx 3.536$
3. **归一化**：$[3/3.536,\ 4/3.536] \approx [0.849,\ 1.131]$
4. **输出**：结果为 $[0.85,\ 1.13]$（保留两位小数）

### LayerNorm vs RMSNorm 对比

| 特性 | LayerNorm | RMSNorm |
|---|---|---|
| 数学公式 | $y = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta$ | $y = \frac{x}{\sqrt{\text{mean}(x^2) + \epsilon}} \cdot g$ |
| 均值处理 | 有。通过减去 $\mu$ 将分布中心移到 0 | 无。不移动分布中心，只控制振幅 |
| 学习参数 | 两个：weight ($\gamma$) 和 bias ($\beta$) | 一个：weight ($g$) |
| 计算开销 | 较高（需计算均值和方差） | 较低（只需计算均方根） |
| 工业应用 | GPT-2, BERT, 早期 Transformer | Llama 2/3, Mistral, 现代大模型标配 |

> [!TIP]
> RMSNorm 在保持相同性能的前提下，计算效率提升约 10%~40%，且在深层网络中表现优异，已成为现代大模型的标配选择。

### 代码实现

```python
class RMSNorm(nn.Module):
    def __init__(self, d_model: int, eps: float = 1e-5, device=None, dtype=None):
        super().__init__()
        factory_kwargs = {'device': device, 'dtype': dtype}
        # 1. 必须初始化为全 1 (ones)
        self.weight = nn.Parameter(torch.ones(d_model, **factory_kwargs))
        self.eps = eps

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x : (batch_size, sequence_length, d_model)

        in_dtype = x.dtype
        # 2. 转换为 float32 以防平方计算时溢出
        x_float = x.to(torch.float32)

        # 3. 计算均方根 (Root Mean Square)
        # 公式: rms = sqrt( mean(x^2) + eps )
        # dim=-1 表示在隐藏层维度计算，keepdim=True 方便后续除法自动广播
        
        ms = x_float.pow(2).mean(dim=-1, keepdim=True)
        rms = torch.sqrt(ms + self.eps)

        # 4. 归一化并乘以可学习的增益参数 g
        result = (x_float / rms) * self.weight

        # 5. 转回原始类型
        return result.to(in_dtype)
