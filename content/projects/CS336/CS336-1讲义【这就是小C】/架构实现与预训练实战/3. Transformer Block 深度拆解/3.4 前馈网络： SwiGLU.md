#### Transformer Block 的两阶段工作模式

一个 Transformer Block 的工作可以概括为 **"先交流，再计算"**：

- **交流阶段（Attention）**：Token 之间互相"看"。通过多头自注意力（MHA），每个词将全句中与自己最相关的特征抓取到自身向量中。这一步本质上是信息搬运，尚未产生质变。
- **计算阶段（FFN）**：每个词回到自身位置，利用前馈网络层对刚抓取的上下文素材进行深度消化。通过高维投影与非线性变换，将零散的上下文信号合并为更高阶的语义概念。

> [!TIP]
> Attention 负责"信息聚合"，FFN 负责"信息加工"。二者缺一不可，共同构成 Transformer 的核心表达能力。

---

#### 从传统 FFN 到 SwiGLU

传统 FFN（GPT-2 时代）的结构为：

$$\text{Linear} \rightarrow \text{ReLU} \rightarrow \text{Linear}$$

现代大模型普遍采用 **SwiGLU**，它引入了门控机制（Gating Mechanism），提供了更强的表达能力。

---

#### SwiGLU 核心公式

设输入为 $x \in \mathbb{R}^{d_{\text{model}}}$，中间维度为 $d_{\text{ff}}$，计算过程拆解为三条路径：

1. **门控分支（Gate Path）**：输入 $x$ 经 $W_1$ 升维至 $d_{\text{ff}}$，随后应用 SiLU 激活函数，决定哪些信息重要：

$$\text{Gate} = \text{SiLU}(x W_1)$$

2. **信号分支（Signal Path）**：输入 $x$ 经 $W_3$ 升维至 $d_{\text{ff}}$，提供实际要处理的内容：

$$\text{Signal} = x W_3$$

3. **融合与降维**：两条路径结果逐元素相乘（$\odot$），再经 $W_2$ 映射回原始维度 $d_{\text{model}}$：

$$\text{SwiGLU}(x) = (\text{SiLU}(x W_1) \odot x W_3) \, W_2$$

其中：
- $W_1 \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}}$
- $W_3 \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}}$
- $W_2 \in \mathbb{R}^{d_{\text{ff}} \times d_{\text{model}}}$

---

#### 激活函数：SiLU（Swish）

SiLU（又称 Swish）的定义为：

$$\text{SiLU}(x) = x \cdot \sigma(x) = x \cdot \frac{1}{1 + e^{-x}}$$

与 ReLU 相比，SiLU 具有以下优势：

- 在 $x=0$ 附近更加平滑，避免了 ReLU 的硬截断
- 允许微弱的负值通过，有助于深层网络中的梯度流动

---

#### 参数规模与 8/3 维度准则

| FFN 类型 | 权重矩阵 | 总参数量 |
|---|---|---|
| 传统 FFN | $W_1 \in \mathbb{R}^{d_{\text{model}} \times 4d_{\text{model}}}$，$W_2 \in \mathbb{R}^{4d_{\text{model}} \times d_{\text{model}}}$ | $2 \times d_{\text{model}} \times 4d_{\text{model}} = 8 \, d_{\text{model}}^2$ |
| SwiGLU FFN | $W_1, W_3 \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}}$，$W_2 \in \mathbb{R}^{d_{\text{ff}} \times d_{\text{model}}}$ | $2 \times d_{\text{model}} \times d_{\text{ff}} + d_{\text{ff}} \times d_{\text{model}} = 3 \, d_{\text{model}} \times d_{\text{ff}}$ |

> [!NOTE]
> **8/3 维度准则**：为使 SwiGLU 的总参数量与传统 FFN（$8d_{\text{model}}^2$）持平，令：
> $$3 \, d_{\text{model}} \times d_{\text{ff}} = 8 \, d_{\text{model}}^2 \quad \Rightarrow \quad d_{\text{ff}} = \frac{8}{3} \, d_{\text{model}}$$
> 即中间维度 $d_{\text{ff}}$ 设为 $d_{\text{model}}$ 的 $\frac{8}{3}$ 倍，而非传统的 4 倍。

**硬件对齐要求**：为优化 GPU 计算效率（如 Tensor Core 对齐），$d_{\text{ff}}$ 通常需要向上取整为 **64 的倍数**。

#### PyTorch 实现

```python
def silu_fn(in_features):
    return in_features * torch.sigmoid(in_features)


class SwiGLU(nn.Module):
    def __init__(self, d_model: int, d_ff: int, device=None, dtype=None):
        super().__init__()
        self.d_ff = d_ff
        self.d_model = d_model
        # W1 和 W3 是并行升维层: d_model -> d_ff
        self.w1 = Linear(d_model, d_ff, device, dtype)
        self.w3 = Linear(d_model, d_ff, device, dtype)
        # W2 是降维层: d_ff -> d_model
        self.w2 = Linear(d_ff, d_model, device, dtype)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        gate = silu_fn(self.w1(x))
        signal = self.w3(x)

        return self.w2(gate * signal)
```

> [!TIP]
> 代码中 `gate * signal` 即公式中的逐元素相乘 $\odot$；`silu_fn` 对应 SiLU 激活函数。注意 `w1` 和 `w3` 是两个独立的并行升维层，并非共享权重。\n
