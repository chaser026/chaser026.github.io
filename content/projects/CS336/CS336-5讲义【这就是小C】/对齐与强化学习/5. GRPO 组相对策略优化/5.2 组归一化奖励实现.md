# 5.2 组归一化奖励实现

> [!NOTE]
> **本节目标**
> - 掌握优势估计的实现细节：理解如何将原始奖励分数转化为策略梯度所需的优势值（Advantage）
> - 对比标准 GRPO（基于标准差）与简化版 GRPO（基于均值）的差异与适用场景
> - 理解训练稳定性：明确 eps 项和标准差归一化对解决奖励信号稀疏问题的作用

---

#### 核心思想

GRPO（Group Relative Policy Optimization）的核心在于：**不直接使用绝对奖励值驱动策略更新，而是将同一问题下的多个回答进行组内相对比较，得到"优势"信号**。这样做消除了不同问题之间奖励尺度的差异，使梯度更新聚焦于"同一问题内哪个回答更好"。

---

## 一、优势计算的数学形式

### 1.1 标准版本（Eq. 28）

$$A_i = \frac{r_i - \mu_G}{\sigma_G + \epsilon}$$

其中：
- $r_i$ 为第 $i$ 个回答的原始奖励
- $\mu_G$ 为该组（同一问题下 $G$ 个回答）的均值
- $\sigma_G$ 为该组的标准差
- $\epsilon$（即 `advantage_eps`）为防止除零的极小值，默认 $10^{-8}$

> 通过减去均值并除以标准差，将组内奖励转化为均值为 0、标准差为 1 的分布。这不仅消除了环境带来的偏移，还统一了梯度的量级。

### 1.2 简化版本（Eq. 31）

$$A_i = r_i - \mu_G$$

由 Dr. GRPO（Liu et al. 2025）提出。当一组内所有回答得分非常接近时，标准差趋近于 0，导致数值计算极其不稳定。此时仅减去均值往往能获得更稳健的收敛效果。

---

## 二、两种版本的核心差异

### 2.1 梯度强度的自动缩放

| 特性 | 标准版（除以标准差） | 简化版（仅减均值） |
|------|----------------------|-------------------|
| 梯度量级 | 自动归一化，始终接近 $\mathcal{N}(0,1)$ | 取决于奖励值的绝对差异 |
| 更新步长一致性 | 所有问题上基本一致 | 随奖励绝对差异线性变化 |
| 极端情况 | 若全组得分相同（如全 0 或全 1），优势精确为 0 | 同左 |

### 2.2 对"极难/极易"问题的权重分配

**标准版：倾向于放大低方差样本的信号**

> 场景：假设 $G=8$，某道难题只有 1 个回答正确（得分 1），其余 7 个全错（得分 0）。此时 $\sigma_G$ 非常小，分母很小，导致那个唯一正确回答的 $A_i$ 会被放大得非常巨大。
>
> ⚠️ **风险**：这可能导致模型过度更新，训练不稳定。

**简化版：维持奖励信号的线性比例**

在上述场景中，正确样本的优势仅为 $1 - 0.125 = 0.875$。这种方式认为：在其他人都做错的情况下，偶然做对的信号不应该被无限放大，从而保护了训练的鲁棒性。

---

## 三、适用场景分析

### 3.1 推荐使用标准版（Eq. 28）的场景

- **奖励函数尺度不一**：同时使用多种奖励（如格式奖、数值对错奖、代码通过率奖），且量级不在同一水平时，标准版能自动将它们拉回到同一评价维度
- **训练初期**：模型还比较"混乱"、采样结果多样性极高时，标准版能快速提取强烈的对比信号，加速格式对齐

### 3.2 推荐使用简化版（Eq. 31）的场景

- **二元奖励任务**：在数学推理（MATH/GSM8K）任务中，奖励通常非黑即白（0 或 1）。Liu et al. [2025] 证明，标准差归一化往往会引入不必要的偏置，简化版能获得更平滑的准确率上升曲线
- **大规模训练**：当 $G$（组大小）非常大时，均值估计已经足够准确，不需要标准差进行额外约束
- **追求训练稳健性**：如果训练过程中经常出现损失值跳变或 NaN，切换到简化版通常是第一个有效的解决方案

---

## 四、训练监控：元数据（Metadata）

在 RL 训练中，需持续观察以下指标以判断奖励质量与归一化是否正常：

| 指标 | 含义 | 健康状态 |
|------|------|---------|
| `mean_reward` | 模型当前的绝对解题能力 | 随训练逐步上升 |
| `max_reward` | 模型的"探索上限"，是否发现过正确路径 | 应逐步趋近满分 |
| `mean_advantage` | 优势均值，理论上应接近 0 | 若长期大幅偏离 0，说明归一化逻辑或梯度累积存在 Bug |

> [!WARNING]
> 如果 `mean_advantage` 持续显著偏离 0（如 > 0.1 或 < -0.1），应优先检查：① `advantage_eps` 是否过大；② `normalize_by_std` 开关是否与预期一致；③ 组内奖励是否存在异常值。

## 五、完整实现代码

```python
def compute_group_normalized_rewards(
    reward_fn: Callable[[str, str], Dict[str, float]],
    rollout_responses: List[str],
    repeated_ground_truths: List[str],
    group_size: int,
    advantage_eps: float = 1e-8,
    normalize_by_std: bool = True,
) -> Tuple[torch.Tensor, torch.Tensor, Dict[str, float]]:
    """
    计算 GRPO (Group Relative Policy Optimization) 的核心组件：组内归一化奖励（即优势 Advantage）。

    该函数执行以下步骤：
    1. 计算每个回答的原始奖励分数。
    2. 将回答按照问题分组（每组 group_size 个）。
    3. 计算组内的平均分（和标准差）。
    4. 将每个回答的分数减去组均值（并可选地除以标准差），得到相对优势。

    Args:
        reward_fn (Callable): 奖励函数。
            - 输入: (模型生成的回答 response, 标准答案 ground_truth)
            - 输出: 一个字典，必须包含 key "reward" (float)。
        
        rollout_responses (List[str]): 模型生成的所有回答列表。
            - 长度 = (问题数量 * group_size)。
            - 顺序隐含了分组逻辑，即前 group_size 个对应第1个问题，接下来的 group_size 个对应第2个问题...
        
        repeated_ground_truths (List[str]): 对应的标准答案列表。
            - 长度必须与 rollout_responses 相同。
            - 对于同一个问题的 group_size 个回答，这里的 ground_truth 是重复的。
        
        group_size (int): 每个问题生成的回答数量 (G)。
            - 用于将扁平的列表 reshape 成 (N, G) 的矩阵。
        
        advantage_eps (float): 防止除零错误的极小值。
            - 当 normalize_by_std=True 时，分母为 (std + eps)。默认 1e-8。
        
        normalize_by_std (bool): 是否除以组内标准差。
            - True: 使用公式 (r - mean) / std (标准 GRPO/DeepSeekMath)。
            - False: 仅使用公式 r - mean (Dr. GRPO 建议的简化版，防止 std 接近 0 时数值不稳定)。

    Returns:
        Tuple[torch.Tensor, torch.Tensor, Dict[str, float]]:
            1. advantages: 归一化后的优势分数，形状 (Total_Samples,)。
            2. raw_rewards: 原始奖励分数，形状 (Total_Samples,)。
            3. metadata: 包含统计信息（如平均奖励、最大/最小奖励等）的字典，用于日志记录。
    """
    
    # --- 1. 基础校验 ---
    # 确保输入数据长度一致，且能被 group_size 整除
    assert len(rollout_responses) == len(repeated_ground_truths), "Response 和 Ground Truth 数量必须一致"
    assert len(rollout_responses) % group_size == 0, "总样本数必须是 group_size 的整数倍"

    # --- 2. 计算原始奖励 (Raw Rewards) ---
    raw_rewards_list = []
    
    # 遍历每一对 (回答, 标答)
    for response, truth in zip(rollout_responses, repeated_ground_truths):
        # 调用外部传入的奖励函数
        # reward_fn 返回示例: {"reward": 1.0, "format_reward": 1.0, ...}
        score_dict = reward_fn(response, truth)
        
        # 我们只取最终的总分 "reward"
        raw_rewards_list.append(score_dict["reward"])
    
    # 将列表转换为 PyTorch 张量，形状为 (Total_Samples,)，例如 (32,)
    # device 默认为 CPU，后续训练时会自动移到 GPU
    raw_rewards = torch.tensor(raw_rewards_list, dtype=torch.float32)

    # --- 3. 组内统计 (Group Statistics) ---
    # 计算有多少个独立的问题 (N)
    num_questions = raw_rewards.shape[0] // group_size
    
    # 关键步骤：Reshape
    # 将一维张量 (N*G, ) 变成二维张量 (N, G)
    # 每一行代表一个问题对应的 G 个回答的分数
    grouped_rewards = raw_rewards.view(num_questions, group_size)
    
    # 计算组内均值
    # dim=1 表示沿着"组"的维度（列）求平均
    # keepdim=True 保持形状为 (N, 1)，这是为了后面能利用广播机制让 (N, G) 减去 (N, 1)
    group_means = grouped_rewards.mean(dim=1, keepdim=True)
    
    # 计算组内标准差 (如果需要)
    if normalize_by_std:
        group_stds = grouped_rewards.std(dim=1, keepdim=True)

    # --- 4. 计算优势 (Advantage Calculation) ---
    if normalize_by_std:
        # 对应公式 (28)
        # 广播机制：(N, G) - (N, 1) -> (N, G)
        # 每个分数减去它所在组的平均分，再除以标准差
        advantages = (grouped_rewards - group_means) / (group_stds + advantage_eps)
    else:
        # 对应公式 (31) - Dr. GRPO 的建议
        # 仅减去均值
        advantages = grouped_rewards - group_means

    # --- 5. 还原形状 ---
    # 将二维的优势矩阵 (N, G) 拉平回一维 (N*G, )，以便和 log_probs 的形状对齐
    advantages = advantages.view(-1)

    # --- 6. 生成元数据 (Metadata) ---
    # 这些数据不参与计算图，仅用于 WandB/日志 监控训练进度
    metadata = {
        "mean_reward": raw_rewards.mean().item(), # 整体平均分
        "std_reward": raw_rewards.std().item(),   # 整体标准差
        "max_reward": raw_rewards.max().item(),   # 最高分
        "min_reward": raw_rewards.min().item(),   # 最低分
        "mean_advantage": advantages.mean().item(), # 平均优势（理论上应接近0）
    }

    return advantages, raw_rewards, metadata
```

## 六、关键参数速查

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `reward_fn` | `Callable[[str, str], Dict[str, float]]` | 必填 | 输入为 (response, ground_truth)，输出字典必须含 `"reward"` 键 |
| `rollout_responses` | `List[str]` | 必填 | 长度 = 问题数 × `group_size`，前 `group_size` 个对应第 1 题 |
| `repeated_ground_truths` | `List[str]` | 必填 | 与 `rollout_responses` 等长，同一问题的标答重复出现 |
| `group_size` | `int` | 必填 | 每题采样回答数 $G$，决定 reshape 维度 |
| `advantage_eps` | `float` | `1e-8` | 防止标准差为 0 时除零，仅在 `normalize_by_std=True` 时生效 |
| `normalize_by_std` | `bool` | `True` | `True` → Eq. 28 标准版；`False` → Eq. 31 简化版 |\n
