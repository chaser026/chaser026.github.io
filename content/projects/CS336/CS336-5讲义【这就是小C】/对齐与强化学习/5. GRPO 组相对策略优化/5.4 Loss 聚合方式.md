# 5.4 Loss 聚合方式

> [!NOTE]
> **本节目标**
> - 理解 `masked_mean`"按实际长度动态平均"的特性，及其在传统 RL 实现中的统治地位
> - 理解 `masked_normalize`"常数归一化"如何改变梯度对长短回复的偏好
> - 通过数学推导，揭示两种方法在 Credit Assignment（信用分配）上的本质差异

---

## 核心矛盾：为什么需要长度归一化

在强化学习训练中，不同回复的长度 $T$ 差异巨大。例如：

- **回复 A**（短）：`"The answer is 42."`（$T \approx 5$）
- **回复 B**（长）：`"Let x be... <1000 words logic> ... thus 42."`（$T \approx 1000$）

如果直接对所有 Token 的 Loss 求和（Sum），回复 B 的梯度量级将是回复 A 的 200 多倍，导致梯度骤增、训练崩溃。因此必须进行长度归一化，使数值保持在安全区间。

---

## 方法 A：masked_mean（动态长度平均）

### 代码实现

```python
def masked_mean(tensor, mask, dim=None):
    # 分子：有效 Token 的总 Loss
    # tensor shape:[micro_B,L], 每个token的loss
    masked_sum = torch.sum(tensor * mask, dim=dim)  # shape:[micro_B,1],
    # 分母：该样本实际的有效长度 T_i
    mask_count = torch.sum(mask, dim=dim)
    return masked_sum / mask_count
```

### 数学本质

$$\mathcal{L}_{\text{masked\_mean}} = \frac{1}{T_i} \sum_{t=1}^{T_i} \ell_t$$

每个样本的 Loss 被除以其自身的有效长度 $T_i$。

### 梯度后果

- **长回复**（$T=1000$）：每个 Token 的梯度被除以 1000，变得极小
- **短回复**（$T=5$）：每个 Token 的梯度被除以 5，相对较大

> [!WARNING]
> `masked_mean` 是 PyTorch `mean` reduction 的默认逻辑：先对每条样本内部求平均，再对 Batch 求平均。这意味着长样本中每个 Token 的梯度权重会被自身长度严重稀释。

---

## 方法 B：masked_normalize（固定常数归一化）

### 代码实现

```python
def masked_normalize(tensor, mask, normalize_constant, dim=None):
    masked_sum = torch.sum(tensor * mask, dim=dim)
    # 分母：一个外部传入的固定常数 C
    return masked_sum / normalize_constant
```

### 数学本质

$$\mathcal{L}_{\text{masked\_normalize}} = \frac{1}{C} \sum_{t=1}^{T_i} \ell_t$$

所有样本的 Loss 都除以同一个常数 $C$（通常设为全局最大序列长度 `max_seq_len`，例如 1024，或一个固定超参数）。

### 梯度后果

- 长回复拥有更大的话语权：如果回复 B（$T=1000$）是正确的，其 1000 个正确 Token 的信号被完整保留
- 模型倾向于学习逻辑链条更长、信息量更大的样本

## 正优势值场景下的梯度特性分析（$A > 0$）

### 设定

假设一个 Batch 中包含 $N$ 条数据，其中两条代表性样本：

| 样本 | 索引 | 长度 |
|------|------|------|
| 短样本 (Short) | $i$ | $T_s$ |
| 长样本 (Long) | $j$ | $T_l$ |

假设每个 Token 产生的原始梯度信号强度相似，记为 $g$。

### A. masked_mean（动态长度平均）—— Sentence-level

短样本单 Token 贡献：

$$\frac{g}{T_s}$$

长样本单 Token 贡献：

$$\frac{g}{T_l}$$

> [!IMPORTANT]
> **梯度稀释现象**：在同一个 Batch 里，长样本中每一个 Token 的梯度权重是短样本的 $\frac{T_s}{T_l}$。若 $T_l = 1000, T_s = 10$，则长样本每个 Token 的权重仅为短样本的 1%。模型会认为长样本里的推理步骤"廉价且不重要"，关键转折点的信号被自身长度严重稀释。

### B. masked_normalize（固定常数归一化）—— Token-level

将归一化常数 $C$ 设为全局固定的最大序列长度（例如 1024），或一个固定超参数。

短样本单 Token 贡献：

$$\frac{g}{C}$$

长样本单 Token 贡献：

$$\frac{g}{C}$$

> [!IMPORTANT]
> **单点平权**：无论样本长短，每一个 Token 对梯度的贡献系数完全相同。

样本总话语权对比：

- 短样本总贡献：$\frac{T_s \cdot g}{C}$
- 长样本总贡献：$\frac{T_l \cdot g}{C}$

**结论**：长样本对参数更新的总推动力是短样本的 $\frac{T_l}{T_s}$ 倍（例如 100 倍）。

### 梯度理解的三个层次

#### 1. 标量的"虚幻性"

最终的 Loss 标量是由成千上万个独立小函数相加得到的。虽然结果是一个数，但 PyTorch 的 Autograd 引擎清楚地知道每个贡献来自长序列还是短序列。

#### 2. 数学核心：导数的线性叠加原理

根据微积分加法求导法则：

$$\nabla_\theta \mathcal{L}_{\text{total}} = \sum_{i=1}^{N} \nabla_\theta \mathcal{L}_i = \sum_{i=1}^{N} \sum_{t=1}^{T_i} \nabla_\theta \ell_{i,t}$$

展开到 Token 级别：

- **样本 A**（短序列，10 个 Token）：只有 10 个梯度向量做矢量和
- **样本 B**（长序列，1000 个 Token）：有 1000 个梯度向量做矢量和

> [!NOTE]
> 即使最终 Loss 标量很小，由于样本 B 贡献了 1000 次导数计算而样本 A 只贡献了 10 次，反向传播后的合力会压倒性地倾向于样本 B 的需求。

#### 3. 为什么 masked_mean 会"磨平"这种权力

- **masked_mean**：样本 B 的 1000 个梯度都被乘以 $\frac{1}{T_l}$，每个人的力气缩小了 100 倍
- **masked_normalize**：所有梯度都除以同一个常数 $C$，B 的 1000 个人力气没怎么减小，人多力量大的优势被完整保留

#### 4. 物理类比：拔河比赛

| 场景 | 描述 |
|------|------|
| 样本 A（短序列） | 派出 10 个人往左拉 |
| 样本 B（长序列） | 派出 1000 个人往右拉 |
| 反向传播（矢量和） | 绳子总张力（Loss 标量）为 0.12，但绳子会疯狂往右移 |
| masked_mean | 裁判强制右边 1000 人只能发 1% 的力 → 10 vs 10 平局 |
| masked_normalize | 裁判不干预 → 1000 人的 B 秒杀 A，主导移动方向 |

## 负优势值场景下的梯度特性分析（$A < 0$）

当模型生成的回复结果错误（优势值 $A < 0$）时，归一化方式直接影响模型对错误路径的修正效率。

### 1. masked_mean：惩罚稀释

单个 Token 产生的负梯度模长与序列长度 $T$ 成反比：

$$\left| \nabla_\theta \ell_t \right| \propto \frac{1}{T}$$

> [!WARNING]
> **工程后果**：对于包含大量重复词汇或逻辑冗余的错误长样本，`masked_mean` 提供的单位惩罚力度较弱，模型无法有效抑制低质量生成模式。

### 2. 响应长度不健康增长的诱因

根据 DAPO 等相关研究的实验观测，`masked_mean` 可能导致响应长度和熵值异常增长：

- **低质量模式留存**：长序列的负梯度信号被自身长度稀释，模型生成的胡言乱语（Rambling）和逻辑循环无法得到及时校正
- **表现**：验证集上平均长度（avg_length）激增，但准确率（accuracy）停滞

### 3. masked_normalize：长度抑制

分母为全局固定常数 $C$，总惩罚力度随有效 Token 数量线性累加：

$$\left| \nabla_\theta \ell_t \right| = \frac{|g|}{C} \quad \text{（不随 } T \text{ 衰减）}$$

- **约束机制**：错误采样的回复越长，负梯度总合力越大，对冗余错误尝试施加更重惩罚
- **训练导向**：强迫模型在不确定路径上保持简洁，仅在优势值为正时才鼓励增加 Token 数量来强化逻辑链条

### 4. 总结对比

| 聚合方式 | 负优势值时的表现 | 对响应长度的影响 | 逻辑偏好 |
|----------|------------------|------------------|----------|
| `masked_mean` | 惩罚随长度增加而稀释 | 易出现不健康的长度增长 | 容忍低质量冗余输出 |
| `masked_normalize` | 惩罚随长度增加而累加 | 自动抑制错误的冗余输出 | 偏好高信息密度的逻辑链 |

> [!IMPORTANT]
> **结论**：在处理具备长思维链特征的推理任务时，`masked_normalize`（Token-level）通过建立"高长度-高惩罚"的负反馈机制，比 `masked_mean` 更有利于抑制逻辑崩溃时的冗余生成，从而维持模型推理过程的严密性。
