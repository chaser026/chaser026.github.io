# 5.3 GRPO损失函数实现

> [!NOTE]
> **本节目标**
> - 掌握 Naive PG、GRPO-No-Clip、GRPO-Clip 三种损失函数的完整数学定义。
> - 深度分析 `clipped_mask` 的判定逻辑，理解 `clip_fraction` 的含义与监控价值。

---

## 一、策略梯度损失函数的统一视角

在 PyTorch 代码中，我们执行的是**梯度下降**（最小化 Loss）。而强化学习的理论目标是**梯度上升**（最大化目标函数 $J$）。为统一二者，代码中的 Loss 定义为目标函数的负值：

$$L = -J$$

以下三种变体均以**逐 Token** 形式给出，涵盖从最基础到工业界标准的完整演进。

---

## 二、三种损失函数的数学定义与代码对应

### 2.1 朴素策略梯度（Naive Policy Gradient / REINFORCE）

- **代码标识**：`loss_type="no_baseline"` 或 `"reinforce_with_baseline"`
- **特点**：最基础形式，不含重要性采样，不含截断机制。

**数学公式**：

$$L^{\text{Naive}} = -\hat{A}_t \cdot \log \pi_\theta(a_t \mid s_t)$$

**含义**：直接根据优势 $\hat{A}_t$ 的正负，增大或减小当前动作的对数概率。

**代码对应**：

```python
loss = - (advantages * policy_log_probs)
```

---

### 2.2 无截断 GRPO（GRPO No-Clip / Off-Policy）

- **代码标识**：`loss_type="grpo_no_clip"`
- **特点**：引入重要性采样比率（Ratio），允许使用旧策略数据更新新策略，但无安全限制。

**数学公式**：

$$L^{\text{No-Clip}} = -r_t(\theta) \cdot \hat{A}_t$$

其中重要性采样比率为：

$$r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)}$$

**含义**：利用比率 $r_t(\theta)$ 修正新旧策略之间的分布偏差。

**代码对应**：

```python
loss = - (ratio * advantages)
```

---

### 2.3 截断 GRPO（GRPO-Clip）——工业界标准

- **代码标识**：`loss_type="grpo_clip"`
- **特点**：DeepSeek-R1 和 PPO 的核心，引入"悲观下界"机制，防止单步更新过大。

**数学公式**：

$$L^{\text{Clip}} = -\min\left(r_t(\theta) \hat{A}_t,\; \text{clip}\big(r_t(\theta),\, 1-\epsilon,\, 1+\epsilon\big) \hat{A}_t\right)$$

展开为两个 surrogate 目标：

$$\text{surr}_1 = r_t(\theta) \cdot \hat{A}_t \quad \text{（激进的、无限制的目标）}$$

$$\text{surr}_2 = \text{clip}\big(r_t(\theta),\, 1-\epsilon,\, 1+\epsilon\big) \cdot \hat{A}_t \quad \text{（保守的、被限制的目标）}$$

**含义**：在最大化目标函数时，取未截断目标和截断后目标的最小值，形成一个保守的优化下界。

**代码对应**：

```python
loss = - torch.min(surr1, surr2)
```

> [!TIP]
> **核心思想**：PPO 逻辑的本质是 $J = \min(\text{surr}_1, \text{surr}_2)$。当 $\text{surr}_2 < \text{surr}_1$ 时，算法选择 $\text{surr}_2$，意味着截断生效、梯度被限制。

## 三、Clip Fraction 的监控逻辑

### 3.1 关键监控代码

在 `compute_grpo_clip_loss` 函数中，以下两行代码揭示了优化器在微观层面的行为：

```python
# 1. 判断是否触发了截断
clipped_mask = (surr2 < surr1).float()

# 2. 计算触发截断的比例
clip_fraction = clipped_mask.mean()
```

> [!WARNING]
> 这两行不仅用于日志记录，更是训练健康度的核心诊断指标。理解 `surr2 < surr1` 的含义，是掌握 PPO/GRPO 训练稳定性的关键。

### 3.2 截断触发条件的分类讨论

我们定义比率 $r_t = \frac{\pi_\theta}{\pi_{\theta_{\text{old}}}}$，截断阈值为 $\epsilon$（通常取 0.2）。

#### 场景 A：优势 $\hat{A}_t > 0$（鼓励该动作）

- **模型行为**：试图增大 $r_t$，导致 $\text{surr}_1$ 上升。
- **截断条件**：当 $r_t > 1 + \epsilon$（例如 $r_t > 1.2$）时。
- **比较**：
  - $\text{surr}_1 = r_t \cdot \hat{A}_t$（继续线性增长，值很大）
  - $\text{surr}_2 = (1+\epsilon) \cdot \hat{A}_t$（被锁死在天花板，值较小）
  - 显然 $\text{surr}_2 < \text{surr}_1$
- **结论**：`clipped_mask = 1`。模型步子迈太大，系统强制"刹车"，不再给予额外奖励。

#### 场景 B：优势 $\hat{A}_t < 0$（惩罚该动作）

- **模型行为**：试图减小 $r_t$，导致 $\text{surr}_1$ 下降。
- **截断条件**：当 $r_t < 1 - \epsilon$（例如 $r_t < 0.8$）时。
- **注意**：此时 $\hat{A}_t$ 是负数。
- **比较**：
  - $\text{surr}_1 = r_t \cdot \hat{A}_t$（$r_t$ 越小，乘积越接近 0，即数值越大；例如 $0.5 \times (-1) = -0.5$）
  - $\text{surr}_2 = (1-\epsilon) \cdot \hat{A}_t$（锁死在底板；例如 $0.8 \times (-1) = -0.8$）
  - $-0.8 < -0.5$，即 $\text{surr}_2 < \text{surr}_1$
- **结论**：`clipped_mask = 1`。模型试图过度抹杀该概率，系统强制"兜底"，保留潜在的探索路径。

### 3.3 clip_fraction 的意义与诊断

`clip_fraction` 统计了一个 Batch 中触发截断的 Token 比例，是调整超参数的"体温计"。

| 状态 | 典型范围 | 诊断 | 后果 |
| :--- | :--- | :--- | :--- |
| 健康 | 2% ~ 20% | 大部分更新在信任区域内，少部分激进更新被修正 | 训练稳定高效 |
| 过高 | > 20% | 学习率（LR）太大，或旧策略太旧（Off-policy 迭代次数太多） | 大量梯度被归零，训练效率极低，容易震荡 |
| 过低 | < 2% | 学习率太小，或 $\epsilon$ 设得太宽 | 更新过于保守，训练极其缓慢，浪费 PPO 大步更新的优势 |

> [!NOTE]
> **实践建议**：`clip_fraction` 的健康范围"2% ~ 20%"为经验参考值，具体需结合任务和模型规模调整。若持续偏高，应优先降低学习率或缩短策略更新间隔。
