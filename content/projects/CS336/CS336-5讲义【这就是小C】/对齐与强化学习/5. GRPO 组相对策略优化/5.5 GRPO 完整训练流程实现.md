# 5.5 GRPO 完整训练流程实现

> [!NOTE]
> **本节目标**
> - 掌握 GRPO 核心超参数的分类与含义
> - 理清从采样（Rollout）到多次梯度更新（Inner Loop）的完整算法闭环逻辑

---

## 核心超参数解析

GRPO 的超参数可划分为三大类：**训练控制参数**、**采样（Rollout）参数**、**算法特定参数**。下表逐一列出各参数的名称、典型默认值及含义。

### 训练控制参数

| 参数 | 典型值 | 含义 |
|---|---|---|
| `--n_grpo_steps` | 200 | 外层迭代总步数。每一步包含一次完整的"采样 + 训练"循环 |
| `--lr` | 1e-5 | 学习率。由于 RL 梯度波动大，通常设得比 SFT 更低（1e-5 或更小） |
| `--train_batch_size` | 256 | 逻辑批大小（Logical Batch Size），模型更新一次权重所参考的样本总数 |
| `--gradient_accumulation_steps` | 128 | 梯度累积步数，用于在有限显存下模拟大 Batch |
| `--epochs_per_rollout_batch` | 1 | Off-policy 数据复用次数，即对同一批采样数据训练多少遍 |

> [!TIP]
> 物理 Micro-batch 大小的计算公式：
> $$\text{Micro-batch size} = \frac{\text{train\_batch\_size}}{\text{gradient\_accumulation\_steps}} = \frac{256}{128} = 2$$

> [!WARNING]
> `--epochs_per_rollout_batch` 增大可提高样本利用率，但过高会导致过拟合旧分布，需谨慎调节。

### 采样（Rollout）参数

| 参数 | 典型值 | 含义 |
|---|---|---|
| `--rollout_batch_size` | 256 | 每一轮外层迭代采样产生的回复总数 |
| `--group_size` (G) | 8 | 组大小，针对每个问题采样的回答个数 |
| `--sampling_temperature` | 1.0 | 控制采样多样性，温度越高探索空间越大 |
| `--sampling_max_tokens` | 1024 | 推理链（CoT）的最大生成长度 |
| `--sampling_min_tokens` | 4 | 最小生成长度，防止空字符串导致计算优势时出现 NaN |
| `--max_len` | 2048 | 训练时的序列最大长度（Prompt + Response） |

> [!IMPORTANT]
> `--group_size` 是 GRPO 的灵魂参数，直接决定优势估计（Advantage）的准确度。
>
> 本轮处理的题目数量计算：
> $$\text{题目数} = \frac{\text{rollout\_batch\_size}}{\text{group\_size}} = \frac{256}{8} = 32$$

> [!WARNING]
> `--sampling_min_tokens` 必须大于 0，否则模型可能输出空字符串，在后续计算组内标准差时产生除零或 NaN。

### 算法特定参数

| 参数 | 典型值 | 含义 |
|---|---|---|
| `--advantage_eps` | 1e-6 | 数值稳定性常数，当组内标准差 $\sigma \to 0$ 时防止除零 |
| `--use_std_normalization` | 开关 | 开启则使用标准 Z-score 归一化（Eq. 28），关闭则仅使用均值中心化（Eq. 31） |
| `--loss_type` | "grpo_clip" | 指定损失函数形式 |
| `--length_norm_type` | "mask_mean" | 长度归一化策略，可选 `mask_mean`（样本平权）或 `mask_normalize`（Token 平权） |

## 完整算法流程详解

GRPO 训练是一个循环递进的过程，包含**初始化**、**外层迭代闭环**、**周期性评估**三个阶段。

### 初始化阶段

- 设定初始策略模型 $\pi_{\theta_{\text{old}}}$
- 初始化优化器状态

### 外层迭代循环（GRPO Outer Steps）

在每一个 Step 中，模型执行以下闭环操作：

#### A. 权重同步（Sync）

将当前训练权重 $\theta$ 加载到 vLLM 推理引擎中，确保采样模型是最新的。

#### B. 组采样（Rollout）

从训练集中随机抽取若干问题，利用 vLLM 对每个问题采样 $G$ 个独立回复（此时 $\theta_{\text{old}} = \theta$）。

#### C. 优势评估（Advantage Estimation）

1. 调用规则奖励函数对所有回复打分 $r_i$
2. 计算组内统计量（Mean / Std）
3. 按照 Eq. 28 或 Eq. 31 计算每个样本相对于组内的优势值 $A_i$

> [!NOTE]
> 优势计算公式：
> - 开启 `--use_std_normalization` 时（Z-score 归一化，Eq. 28）：
>   $$A_i = \frac{r_i - \text{mean}(r)}{\text{std}(r) + \epsilon}$$
> - 关闭时（仅均值中心化，Eq. 31）：
>   $$A_i = r_i - \text{mean}(r)$$
>
> 其中 $\epsilon$ 即 `--advantage_eps`（1e-6），用于数值稳定。

#### D. 准备旧概率（Old Log-probs）

在开启更新前，记录当前模型对这批数据的对数概率 $\log \pi_{\theta_{\text{old}}}(a_i|q)$，作为后续计算重要性采样比率和 Clipping 的基准。

#### E. 内部优化更新（Inner Train Steps）

1. 将采样数据打乱（Shuffle），进入训练子循环
2. 按照 `train_batch_size` 划分逻辑批次
3. 执行 `gradient_accumulation_steps` 次梯度累积（Micro-batches），每次包含：
   - 前向传播计算新概率 $\log \pi_{\theta}(a_i|q)$
   - 计算比率 $r_i(\theta) = \frac{\pi_{\theta}(a_i|q)}{\pi_{\theta_{\text{old}}}(a_i|q)}$
   - 计算带有截断机制的 GRPO 损失
   - 执行反向传播
   - 执行 `optimizer.step()` 更新模型参数 $\theta$

> [!TIP]
> 内部训练子循环的伪代码逻辑如下：

```text
for inner_step in range(num_inner_steps):
    for micro_batch in dataloader:          # 按 train_batch_size 划分
        # 前向传播
        new_logprobs = model(micro_batch.inputs)

        # 重要性采样比率
        ratio = exp(new_logprobs - old_logprobs)

        # GRPO 截断损失（grpo_clip）
        loss = -mean(min(ratio * A, clip(ratio, 1-eps, 1+eps) * A))

        # 反向传播 + 梯度累积
        loss.backward()

    optimizer.step()
    optimizer.zero_grad()
```

### 周期性评估（Evaluation & Saving）

- 每隔固定数量的外层 Step，在验证集上执行 Greedy 采样（$\text{temperature}=0$），评估模型真实准确率（Accuracy）
- 保存 Checkpoint，记录 WandB 日志（Loss、Entropy、Clip Fraction、Reward）

> [!NOTE]
> 评估阶段使用 Greedy 采样而非随机采样，目的是消除采样噪声，获得稳定的准确率指标。
