# 6.3 长度归一化

> [!NOTE]
> **本节目标**
> - 理解长度归一化在 GRPO 训练中的作用机制及其对模型生成长度的影响
> - 掌握 token-level 与 sequence-level 损失聚合策略的适用场景与实验结论
> - 通过 Math 12k 与 GSM8K 实验数据，分析不同归一化方式对准确率和生成长度的影响

## Math 12k 实验结果分析

本实验对比了两种长度归一化策略：

- **`mask_normalize`**：token-level 损失聚合（按每个 token 单独计算并求和/平均）
- **`mask_mean`**：sequence-level 损失聚合（先对序列内 token 求均值，再聚合）

### 生成长度对比

| 指标 | `mask_normalize` | `mask_mean` | 差异 |
|---|---|---|---|
| `avg_length_correct`（正确样本平均长度） | 较短 | 较长 | `mask_normalize` > `mask_mean`，差异约 30–40 token |
| `avg_length_incorrect`（错误样本平均长度） | 较短 | 较长 | `mask_mean` > `mask_normalize`，差异约 400 token |
| `avg_length`（整体平均长度） | 较短 | 较长 | 受 `mask_mean` 在错误样本上的显著偏大影响 |

### 准确率对比

两种策略的最终准确率**约相当**，未出现显著差距。

> [!IMPORTANT]
> **核心结论**
> - 在**正确样本**上，token-level 损失聚合（`mask_normalize`）更有利于强化长逻辑链——它不会按序列长度稀释梯度，从而保留长推理链的完整优化信号。
> - 在**错误长样本**（包含大量重复词汇或逻辑冗余）上，token-level 聚合建立了"错误长度–惩罚强度"正相关机制，从数学上抑制冗余错误生成。
> - `mask_mean` 在负优势场景下会削弱惩罚力度，容易导致生成长度失控。

参考来源：https://arxiv.org/pdf/2508.08221#page=13.74

## Token 级损失聚合策略对不同模型的影响

### 核心发现

Token-level（按每个 token 单独计算损失并聚合）与 Sequence-level（按整条响应聚合）损失策略的效果**高度依赖模型类型**。

#### 对基础模型（Base Models）

- Token-level 聚合能够保证**每个 token 对优化信号都有贡献**
- 改善收敛速度、最终精度和鲁棒性
- 在复杂数据集上表现尤为明显

#### 对对齐/指令调优模型（Aligned / Instruct Models）

- 基础推理能力已经较强，Token-level 聚合对收敛和精度提升**有限**
- 甚至可能影响输出的结构和一致性
- 在大部分数据集和设置下，**Sequence-level 聚合反而表现更好**

> [!NOTE]
> **策略选择建议**
> - **基础模型** → 优先使用 Token-level 损失聚合
> - **指令调优/对齐模型** → 优先使用 Sequence-level / Response-level 损失聚合，以保持输出结构与一致性
